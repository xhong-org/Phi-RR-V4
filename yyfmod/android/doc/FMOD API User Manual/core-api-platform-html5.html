11. Core API Reference | HTML5 Specific

Extra APIs for HTML5 platform.

  • getValue Retrieve a value from a specific FMOD memory address.
  • setValue Store a value at a specific FMOD memory address.
  • copyToPtr Copy a source array to an FMOD memory address.

setValue

Store a value at a specific FMOD memory address.

JS

function setValue(
    ptr: number, 
    value: number, 
    type: string
)
ptr
Number representing the FMOD.HEAPU8 memory address.
value
The value to be stored.
type
value type specified as a string. ie 'i8', 'i16', 'i32', 'i64', 'float', 'double'. (UTF-8 string)

FMOD.HEAPU8 memory addresses are passed in via some DSP and file callbacks.

Example usage.

for (var samp = 0; samp < length; samp++)
{
    for (var chan = 0; chan < outchannels; chan++)
    {
        // This DSP filter just halves the volume! Input is modified, and sent to output.
        let val = FMOD.getValue(inbuffer + (((samp * inchannels) + chan) * 4), 'float') * dsp_state.plugindata.volume_linear;

        FMOD.setValue(outbuffer + (((samp * outchannels) + chan) * 4), val, 'float');
    }
}

Wrapper for the emscripten function.

See Also: getValue,copyToPtr

getValue

Retrieve a value from a specific FMOD memory address.

JS

function getValue(
    ptr: number,
    type: string
): number
ptr
Number representing the FMOD.HEAPU8 memory address.
type
value type specified as a string. ie 'i8', 'i16', 'i32', 'i64', 'float', 'double'. (UTF-8 string)

FMOD.HEAPU8 memory addresses are passed in via some DSP and file callbacks.

Example usage.

for (var samp = 0; samp < length; samp++)
{
    for (var chan = 0; chan < outchannels; chan++)
    {
        // This DSP filter just halves the volume! Input is modified, and sent to output.
        let val = FMOD.getValue(inbuffer + (((samp * inchannels) + chan) * 4), 'float') * dsp_state.plugindata.volume_linear;

        FMOD.setValue(outbuffer + (((samp * outchannels) + chan) * 4), val, 'float');
    }
}

Wrapper for the emscripten function.

Return value

If this method succeeds, it returns an integer value stored at the specified memory address.

See Also: setValue

copyToPtr

Copy a source array to an FMOD memory address.

JS

function copyToPtr(
    dest: number, 
    src: ArrayBuffer | ArrayBufferView | number[], 
    length: number
)
dest
Number representing the FMOD.HEAPU8 memory address. Supplied by FMOD callbacks.
src
Source array buffer.
length
length to copy in bytes.

Example usage.

// Note! For the Range: feature the server needs to send the following headers back on
// audio/file delivery routes:
//     Access-Control-Allow-Origin: *
//     Access-Control-Allow-Headers: Range
//     Access-Control-Expose-Headers: Content-Range, Content-Length

fetch(info.handle, {
    headers: { Range: `bytes=${start}-${end}` }
}).then(function(res){
    res.arrayBuffer().then(function(buf)
    {
        FMOD.copyToPtr(info.buffer, buf, buf.byteLength);

        info.bytesread = buf.byteLength;
    });
}).catch (function(e) {
    info.done(info, FMOD.ERR_FILE_COULDNOTSEEK);
});

See Also: setValue,getValue,FMOD_FILE_ASYNCREAD_CALLBACK
